# tui-styles

> Terminal-inspired themes and UI customizations for modern applications.

```
┌─────────────────────────────────────────────┐
│                tui-styles                   │
│     Minimal • Monospace • Terminal UI       │
└─────────────────────────────────────────────┘
```

A collection of terminal-inspired themes built around clean typography, sharp borders, and distraction-free interfaces.

## Themes

### YouTube — Rosé Pine TUI

Transform YouTube into a terminal-style interface using the Rosé Pine color palette.

**Features**

* Rosé Pine colors
* JetBrains Mono typography
* Sharp borders and minimal styling
* TUI-inspired controls and layout
* Compatible with Stylus

**Install**

https://github.com/syahrilshahiran/tui-styles/raw/main/stylus/tui-youtube-rose-pine.user.css

---

### GitHub — Rosé Pine TUI

Transform GitHub into a terminal-style interface using the Rosé Pine color palette.

**Features**

* Rosé Pine, Moon and Dawn presets
* Selectable accent color (Love, Gold, Rose, Pine, Foam, Iris)
* JetBrains Mono typography
* Sharp borders and no rounded corners
* Compatible with Stylus

**Install**

https://github.com/syahrilshahiran/tui-styles/raw/main/stylus/tui-github-rose-pine.user.css

---

### Reddit — Rosé Pine TUI

Transform Reddit into a terminal-style interface using the Rosé Pine color palette.

**Features**

* Rosé Pine, Moon and Dawn presets
* Selectable accent color (Love, Gold, Rose, Pine, Foam, Iris)
* JetBrains Mono typography
* Sharp borders and no rounded corners where possible
* Compatible with Stylus

> **Note:** Reddit's current site is built from web components with shadow DOM, which Stylus
> can't restyle directly. Only inherited properties (CSS variables, color, fonts) reach inside
> shadow roots, so a few elements keep Reddit's rounded corners or default fills.

**Install**

https://github.com/syahrilshahiran/tui-styles/raw/main/stylus/tui-reddit-rose-pine.user.css
